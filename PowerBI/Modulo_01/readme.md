# 🚀 Desafio Power BI – DIO

## 📌 Entendendo o Desafio
A proposta é explorar os conceitos aprendidos e replicar o projeto prático.  

- Arquivos de banco de dados  
- Links para templates no Figma  
- Documentação complementar  

---

## 🎨 Páginas – Requisitos
A página deve conter os seguintes elementos:

- **[Visual mapa 1](ca://s?q=Visual_mapa_1_sales_unidades)**: Soma de *sales* e unidades vendidas por país  
- **[Visual mapa 2](ca://s?q=Visual_mapa_2_profit_por_pais)**: Soma de *profit* por país  
- **[Visual de pizza](ca://s?q=Visual_pizza_profit_por_segmento)**: Lucro por segmento  

---

## 🔧 Ajustes e Publicação
- **[Disposição dos visuais](ca://s?q=Disposicao_dos_visuais_relatorio)**: verificar a organização no relatório  
- **[Nomes dos visuais](ca://s?q=Modificar_nomes_dos_visuais)**: torná-los claros e diretos, de acordo com o contexto  
- **[Dicas de ferramentas](ca://s?q=Campos_dicas_de_ferramentas)**: confirir os campos utilizados  
- **[Publicação](ca://s?q=Publicar_relatorio_power_bi)**: publicar o relatório final  
- **[Compartilhamento](ca://s?q=Compartilhar_relatorio_power_point)**: exportar como suplemento no PowerPoint ou salvar o projeto no Power BI caso não tenha PowerPoint

## 🎯 Objetivo
Este desafio tem como foco **treinar a criação de visuais no Power BI**, desenvolvendo familiaridade com os recursos da ferramenta.  
Nos módulos avançados, aprenderemos a trabalhar com layouts mais elaborados e relatórios profissionais.
