# Primeiros Passos com BI ✏️

🧠 Este repositório reúne o material de estudo do **Bootcamp de Power BI com Inteligência Artificial**, com foco em aprendizado prático sobre organização de dados, criação de análises e construção de dashboards voltados à tomada de decisão.

O curso aborda:
- Fundamentos de IA
- SQL e DAX
- Modelagem dimensional (Star Schema)
- Storytelling com dados
- Integração com MySQL e Azure
- Conceitos de Machine Learning, LLMs e IA Generativa aplicados ao dia a dia

---

## 🎯 Objetivos de Estudo
- [NotebookLM](ca://s?q=Estudar_NotebookLM)
- [Power BI](ca://s?q=Estudar_Power_BI)
- [KPIs, métricas e visualizações](ca://s?q=Aprender_KPIs_e_visualizações)
- [Cálculos com DAX](ca://s?q=Aprender_DAX)
- [Estruturação de dados com Star Schema](ca://s?q=Aprender_Star_Schema) e modelagem dimensional
- [Integração com MySQL e Azure](ca://s?q=Integração_com_MySQL_e_Azure) em cenários corporativos
- Desenvolvimento de um **Dashboard Gerencial para Tomada de Decisões** como projeto final
- Transformação de dados brutos em informações estratégicas

---

## 🚀 Projeto Final
O objetivo é consolidar os aprendizados em um **Dashboard Gerencial no Power BI**, capaz de transformar dados em insights estratégicos para apoiar decisões corporativas.
